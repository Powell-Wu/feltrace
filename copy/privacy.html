隐私说明

版本日期：2026-10-10。本说明适用于 FELTrace 的 GitHub Pages 公开阅读预览版，维护者为 GitHub 账户 Powell-Wu。

浏览器本地数据

本站无需注册登录。收藏及主题设置保存在当前浏览器本地，不传送到本站后台，也不会跨设备同步。清除浏览器的网站数据即可删除这些记录；浏览器拒绝存储时部分功能只在当前页面临时可用。

托管与访问记录

本站由 GitHub Pages 托管。GitHub 会为安全目的记录访问者 IP 地址，相关处理适用 GitHub 隐私声明。本站未额外加入访问统计、广告追踪或在线反馈数据库。

外部链接与公开反馈

点击论文原文、设施网站及项目 Issues 后，会访问相应第三方服务，适用其隐私规则。GitHub Issues 中提交的内容通常公开可见；请勿提交敏感个人信息。反馈内容的修改与删除按 GitHub 的权限及功能处理。

模型处理与联系

中文导读在资料处理阶段生成。读者浏览、搜索或收藏不会触发模型调用，本站不会将读者的搜索词发送到模型服务。隐私及更正请求可通过 项目 Issues 联系维护者。
