关于 FELTrace

FELTrace 是自由电子激光光源与加速器研究的阅读索引，收录论文、设施资讯、学术精选及简报。此版本为公开只读预览。

阅读与核查

中文导读与精选由模型辅助生成，材料依据、真实发表时间、首次收录时间及原文入口保留在条目中。摘要、题录和全文是不同的材料状态；收录与精选不代表科学结论已经验证。引用和核查技术参数时，请回到论文原文。

更新方式

本机系统生成公开快照后部署到 GitHub Pages。页面标注的是快照更新时间，资料的发表和收录日期分别展示。网站不提供后台登录、在线模型调用或实时数据接口。

更正与联系

由 GitHub 账户 Powell-Wu 维护。错误、更正、下架及隐私相关问题可通过 项目 Issues 联系。Issues 是公开渠道，请勿提交个人敏感信息。
