使用说明

版本日期：2026-10-10。本说明适用于 FELTrace 的 GitHub Pages 公开阅读预览版，维护者为 GitHub 账户 Powell-Wu。

用途与内容

本站用于自由电子激光光源及加速器相关文献发现、阅读导航与研究交流。可浏览、收藏及分享条目链接。中文导读与精选由模型辅助生成，可能有遗漏或误解；科学结论、实验条件、参数和正式引用请以原始资料为准。

来源与许可

论文、原始摘要、图片及第三方内容的权利归相应权利人。本站保留来源与原文入口，仅按来源许可展示相应内容。访问本站不授予第三方全文、图片或数据的批量再分发权；复制、转载或商业使用须遵循相应许可并取得所需授权。

更新、更正与下架

本站为定期导出的静态快照，可能落后于原文修订或撤回状态。请核对页面更新时间及来源页面。来源方或读者可通过 项目 Issues 提交更正、下架或展示调整请求；请提供条目地址与具体问题，不要在公开反馈中提交敏感信息。
